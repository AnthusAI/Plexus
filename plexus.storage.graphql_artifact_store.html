plexus.storage.graphql_artifact_store module

Application-authorized artifact transfer over GraphQL-issued HTTPS tickets.

This module deliberately knows nothing about dashboard authentication or object storage credentials. Callers provide a dashboard-client-compatible executor; the application authorizes an artifact transfer and the store transfers the bytes only through the resulting HTTPS URL.
