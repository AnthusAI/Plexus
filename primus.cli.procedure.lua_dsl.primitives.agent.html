Bases: object

Executes LLM agent turns with tool calling.

Each agent has: - System prompt (instructions) - Initial message (kickoff) - Conversation history - Available tools - LLM instance

Initialize an agent primitive.

Args:

name: Agent name (e.g., “worker”, “assistant”) system_prompt: System prompt for the agent initial_message: Initial user message to kickoff llm: LangChain LLM instance with tools bound available_tools: List of available tool objects tool_primitive: ToolPrimitive instance for recording calls stop_primitive: StopPrimitive instance for stop detection iterations_primitive: IterationsPrimitive for tracking turns chat_recorder: Optional ProcedureChatRecorder for logging conversations state_primitive: Optional StatePrimitive for steering watermarks
