primus.cli.procedure.scheduled_continuation module

Strict shared contract for native Tactus scheduled continuations.

The payload is intentionally small because it is copied into durable Procedure and Task metadata. It contains no provider error text or mutable execution state; the indexed Tactus checkpoint remains the authority.
