primus.cli.procedure.tactus_adapters package

Primus adapters for Tactus protocols.

These adapters implement Tactus protocols to integrate the standalone Tactus library with Primus’s GraphQL-based infrastructure.

class primus.cli.procedure.tactus_adapters.OptimizerExternalChildResolver(*, backend: Any, account_id: str)

Bases: object

Resolve exact, persisted optimizer children without account scans.

A malformed/missing/mismatched record is an incomplete child, never a substitute identity and never a success. Failed or cancelled children are terminal only after both indexed records corroborate the same immutable launch identity.
